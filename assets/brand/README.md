# Victor Mascaro — Logo kit v1.1

Concept: **Selection**. The name sits inside a design-tool selection frame with corner handles and a cursor.

## Files

| Folder | What's inside |
|---|---|
| `svg/` | Vector logos, text converted to outlines (no fonts needed). Primary, horizontal and monogram in five colorways, plus the app icon. |
| `png/` | Transparent PNGs. Logos at 1200 and 2400 px wide, monograms at 512 and 1024 px. |
| `favicon/` | `favicon.ico` (16/32/48), `favicon.svg`, 16/32 PNGs, `apple-touch-icon.png` (180), 192/512 icons, `site.webmanifest`. |
| `social/` | Open Graph images, 1200 × 630, light and dark. |
| `snippets/` | `brand.css` + `header-brand.html`: the live HTML/CSS header lockup using the portfolio's CSS variables. |

## Colorways

- **light**: for Paper `#EEF3FA` / white backgrounds (default)
- **dark**: for Night `#0A1430` (the site's dark theme)
- **reverse**: for Accent Blue `#0B63C9`
- **black**: one color, Ink `#0B1530`
- **white**: one color, white, for dark or photo backgrounds

## Spec (N = name size)

- Name: Bricolage Grotesque, weight 720, opsz 48, tracking −0.03em
- Frame: stroke 0.036 N, padding 0.31 N from cap height and baseline, 0.32 N at the sides
- Handles: squares with a side of 5 × the frame stroke (0.18 N), centered on the corners
- Monogram and app icon: the same frame at 0.05 N stroke and 0.25 N handles. The app icon is the monogram recolored white.
- Cursor: the tip sits exactly on the center of the bottom-right handle, in every version
- Tag: "UX/AI · Gamification · Game Design" (middle dots, as on the portfolio). JetBrains Mono 600, 0.243 N, caps, +0.1em, centered on cap height in an Accent Blue pill. Same size in the horizontal version. The site-header lockup drops the tag.
- Clear space: the height of the tag (0.486 N) on every side
- Minimum size: primary 340 px, horizontal 600 px (wide slots only), monogram 40 px, favicon 16 px
