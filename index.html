          Overview

          One language for every page

          This tab documents the design language of this portfolio: its logo, color, type, space, motion, icons and components. Everything on it is rendered with the site’s own CSS, and every value is read from that CSS when the page loads, so it can’t drift from the tabs it describes.

          Plain and concrete

          First person and specific, with no slogans. Every number says what it measured and whether it was measured, projected or estimated.

          Game as a light layer

          XP, quests and the designer card sit on top of the portfolio as decoration. Nothing is locked, and the game layer can be switched off.

          Built in code

          Plain HTML, CSS and JavaScript on GitHub Pages, with no framework and no build step. Prototypes are built in code too, with Claude Code.

          One focus per block

          Text sits on the page, divided by space. Only a block’s main point gets a card, and only a word or two of it gets a highlight.

          Construction

          • Name: Bricolage Grotesque 720, optical size 48, tracking −0.03em. With N as the name size:
          • Frame: a stroke of 0.036 N, 0.31 N from cap height and baseline, 0.32 N at the sides.
          • Handles: squares, each side 5 × the frame stroke, centered on the corners.
          • Cursor: its tip sits on the center of the bottom-right handle, in every version.
          • Tag: “UX/AI · Gamification · Game Design” in JetBrains Mono 600, caps, +0.1em, centered on cap height in an accent pill.

          Do and don’t

          • Use the supplied files; the text is converted to outlines, so no font is needed.
          • Use the light colorway on paper and white, the dark one on night, reverse on accent blue, and white on photos.
          • Keep the frame, the four handles and the cursor together.

          Highlights

          50% of workers don’t file expense reports for money they’re owed.

          How might we make an expense report that fills itself in from a photo, highlights anything it isn’t sure about, and checks every receipt against the expense policy?

          To stress part of a sentence, color it and set it in bold: .hl in --accent for the idea, .hl-gold in --gold-ink for a number. One highlight per block, so it still stands out, and never an underline or a marker: the gold underline belongs to the hero title. On a prototype page, the problem’s number leads instead: gold and two lines tall, beside the sentence it counts.

                  Voice

                  How the site talks

                  • First person and specific. “I designed the advisor dashboard”, not “the team delivered solutions”.
                  • No slogans and no “lessons”. Say what happened and what changed.
                  • Numbers need context. Every number says what it measured and whether it was measured, projected or estimated. Never add one that can’t be backed up.
                  • Both languages, always. Every string exists in English and Brazilian Portuguese; Portuguese runs about 20% longer, so layouts are checked in both.
                  • Sentence case for headings and labels, and separators written as “ · ” with a space on each side.

                  Accessibility

                  Focus, contrast, motion and ARIA

                  Focus

                  Every interactive element shows a focus ring when reached with the keyboard: a 2.5px --accent outline, 3px away from the element (cards and tabs use 3px). In the contact band it turns gold. Press Tab to try it on these:

                  A primary buttonA ghost buttonProjectsKnomee, Betsie and mobile games

                  Contrast

                  The text pairs the site uses, computed from the values in main.css for both themes. Body text needs 4.5:1 (AA); large text 3:1.

                  PairLightDark

                  Motion

                  • With reduced motion on, every animation and transition is cut to an instant, and the hero card’s float and tilt stop.
                  • The language switch skips its typing, the logo cursor doesn’t nudge, and quest hints show a static outline instead of a pulse.
                  • Tab entrances and scroll reveals only move content; nothing is hidden waiting for an animation.

                  ARIA and structure

                  • A “Skip to content” link comes first, and the page has one h1 with headings in order.
                  • Landmarks have labels: nav aria-label="Primary", the career path and the section tabs.
                  • Current places use aria-current; toggles use aria-pressed (skill nodes, course chips, compare tags) or aria-expanded (menu, quest log).
                  • The quest log and case sheet are dialogs labelled by their titles; the skill detail panel is aria-live="polite"; toasts announce through a polite live region.
                  • Decorative icons are aria-hidden; images have alt text, and the logo’s alt is the name and tag.
                  • The language button says what it does: “EN, switch to Portuguese”.
